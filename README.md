**Traitle**



Welcome to Traitle! Thank you for taking the time to play my game. I truly appreciate your interest.



**How to Download and Play**



1\. Download the `Traitle.jar` file from this repository.

2\. Ensure that Java is installed on your computer.

3\. Double-click `Traitle.jar` to launch the game.

4\. Follow the instructions displayed within the game.



**Launching Through the Terminal**



If double-clicking the file does not launch the game, open a terminal in the directory containing the downloaded file and execute the following command:



`java -jar Traitle.jar`



**Requirements**



* Java Runtime Environment (JRE) or Java Development Kit (JDK).
* A computer capable of running Java desktop applications.
